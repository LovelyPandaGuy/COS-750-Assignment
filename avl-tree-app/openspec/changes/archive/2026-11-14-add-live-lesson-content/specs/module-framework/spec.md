# Spec Delta

## REMOVED Requirements

### Requirement: Steps follow the Gagné order
**Reason**: C2 to C8 no longer exist as TypeScript step records built from engine facts. Lessons are JSON screens from `src/live_content/lessons/`, which is the ID's content format (ID 12), played by one lesson player.
**Migration**: See `lesson-player` (order, frame, navigation, skip, focus), `lesson-blocks` (one component per screen type), `live-content` (validation, including engine cross-checks of every typed value, which replaces facts, claims and the typed-number rule) and `step-replay` (lesson replays). Practice, prediction and Do it yourself steps return as JSON questions in `add-live-lesson-questions`.
