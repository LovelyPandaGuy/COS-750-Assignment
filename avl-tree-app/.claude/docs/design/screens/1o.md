## States shown

Per-outcome: secure, developing, not yet. Confident-but-wrong flags. Auto and own lecture questions.

## Links

- Review links → the unit / module ([1e](1e.md), [1f](1f.md)). See why → the item's explanation.

## Notes (word for word)

1. Status per outcome uses symbol + word + border (solid / dashed / dotted). Evidence = latest check attempts only; no total mark.
2. Confident-but-wrong comes from the optional ConfidenceRating; framed as “worth a look”, not as a failure.
3. List auto-built from retry-cap drafts, confident-wrong items and “not yet” outcomes; all editable and removable.
4. Print view = questions + statuses only, plain text, one page. Nothing leaves the device unless the student exports it.

## Keyboard and accessibility

- Status = symbol + word + border style.
- Questions editable and removable.
