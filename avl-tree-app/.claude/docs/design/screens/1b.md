## States shown

- First visit: ResumeCard hidden.
- Returning: ResumeCard shown.
- ConfirmDialog open.

## Links

- Start button → Diagnostic ([1c](1c.md)).
- Resume → Unit hub ([1e](1e.md)) with the current activity focused.

## Notes (word for word)

1. First visit → Diagnostic. Copy frames it as a warm-up, not a test.
2. ResumeCard reads browser storage; hidden on first visit. Resume goes to the Unit hub with the current activity focused.
3. Privacy notice is always visible on Start (not behind a link).
4. Reset is a deliberate two-step (link → ConfirmDialog, focus trapped, Esc cancels).

## Keyboard and accessibility

- ConfirmDialog traps focus; Esc cancels (note 4).
- Privacy notice is never behind a link (note 3).
- 44 px targets, single focus style (INDEX rules).
