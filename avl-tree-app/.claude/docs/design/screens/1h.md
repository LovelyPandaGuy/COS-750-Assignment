## Notes (word for word)

1. Selection = thick square frame + “SELECTED” label. Menu also opens via Enter; announces “Node 20 selected, height 3, balance +2, unbalanced”.
2. InOrderStrip carries the U2 idea visually; in U2 it animates to prove nothing moved.
3. Interactive attempts in Explore are practice only — they never count toward readiness.

## Keyboard and accessibility

- Tab into tree; ↑ parent, ← → children; Enter selects (and opens the menu); R / L rotate; Esc cancels; Ctrl+Z undo.
- Selection announced: “Node 20 selected, height 3, balance +2, unbalanced”.
- Selected = rounded-square frame + word "SELECTED".
