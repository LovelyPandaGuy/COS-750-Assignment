## Notes (word for word)

1. Each representation toggles independently per concept (diagram, text, pseudocode, read-aloud). Watch ↔ Do it yourself is a separate switch. Framed as choices, not learning styles.
2. Keys: Space play/pause, ← → step, [ ] speed. Step back fully restores the previous tree state. Respects reduced-motion (steps snap).
3. Every node shows h and bf. Unbalanced node: thick + dashed double ring AND a “⚠ UNBALANCED” text label.
4. Text description updates per step: “Root 40 (height 4, bf +1). Left child 20 (height 3, bf +2, unbalanced)…”. Same layout serves the worked example (no predict prompt, more text).

## Keyboard and accessibility

- Space play/pause; ← → step; [ ] speed. Reduced motion: steps snap.
- TreeView role=img with a live description; StepExplanation is aria-live.
- Current pseudocode line: inverted + ▶ marker (not colour alone).
- Unbalanced node: double ring + text label.
