## States shown

- Needs review (one or more sub-skills).
- All secure (variant box).

## Links

- Start primer → U0 (BST refresher). Skip / Start U1 → first AVL unit, via hub ([1e](1e.md)).

## Notes (word for word)

1. One row per sub-skill: secure / needs review. No total score, no percentage.
2. Routing: any “needs review” → recommend U0 (student can still skip). All secure → U1; U0 stays available but optional.

## Keyboard and accessibility

- Status carries icon + word + border style; never colour alone (annotation ①).
- One primary action.

## Requirement and outcome IDs

FR-DIA-02 (per-skill list, no score), FR-DIA-03 (routing), FR-DIA-04 (path choice), FR-MOT-04 (no score wording). Outcome: PRE; no LO.

- U0 / U1 naming vs C1 / C2 and the BST refresher (D1).
