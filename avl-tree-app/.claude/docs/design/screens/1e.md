## Notes (word for word)

1. Done / current / upcoming each use a different border (solid / thick / dashed), fill and word — not colour. Past = where you've been; “You are here”; dashed = where you're going.
2. Reordering is per unit and saved locally. Default order shown first.
3. One primary action. No points, streaks, or comparison anywhere.
4. Guided path is the default; units in “own” mode are never locked, only annotated.

## Keyboard and accessibility

- Reorder by drag handle or ↑/↓ buttons (keyboard); "Reset to default order".
- Status by border + fill + word, not colour (note 1). Design system: progress map completion uses neutral ink, not mastery colours.

## Requirement and outcome IDs

FR-LRN-03 (progress map), FR-LRN-05 / FR-SCA-05 (module completes through its check), FR-MOT-04 (no points), FR-VIS-08 (sandbox entry, D11, D60), FR-VIS-10. LO: per unit, `[OPEN]` until U→C mapping.
