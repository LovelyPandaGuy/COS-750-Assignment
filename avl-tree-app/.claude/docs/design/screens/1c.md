## Notes (word for word)

1. Stepper shows the sub-skill being checked, not a running score. No right/wrong shown per item during the diagnostic (keeps it quick and low-stakes).
2. Confidence is optional; used later to flag “confident but wrong”. Radio group, arrow-key operable.
3. Skip counts as “needs review” for that sub-skill — no penalty wording.
- (unnumbered) Keyboard: A–D or arrows to pick, Enter = next. Tree has a text description toggle for screen readers.

## Keyboard and accessibility

- A–D or arrow keys pick an option; Enter = next.
- ConfidenceRating is a radio group, arrow-key operable.
- TreeView has a text description toggle for screen readers (FR-VIS-07).

## Requirement and outcome IDs

FR-DIA-01 (items tagged to sub-skills), FR-ASM-01 (question model), FR-VIS-07 (text description), FR-VIS-10 (keyboard, targets). Outcome: PRE (C1 prerequisites, `beyond ID`); no LO.
