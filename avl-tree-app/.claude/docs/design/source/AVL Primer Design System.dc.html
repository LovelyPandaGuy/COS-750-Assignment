border.subtle (#D5D9E2, 1.4:1) is decorative only — card edges, dividers. Anything a student must find to operate (inputs, radios, toggles, step buttons) uses border.control. Disabled text (#5E6577) is kept readable even though WCAG exempts it.

Additions to your spec

  • border.control #767D8F — your border #D5D9E2 is only 1.4:1, below the 3:1 needed for control boundaries.
  • Primary hover / pressed / tint (#2A3588, #222C73, #ECEEF9) and a code highlight tint (#E4E7F7).
  • Tints for Bloom, mastery and feedback backgrounds; every foreground on them passes 4.5:1.
  • Not-quite-yet icon colour #3B5170 (blue-grey) and correct-panel border #9FD3CC.
  • Bloom chips carry a shape glyph (circle / diamond / triangle) as well as the word.
  • A neutral tree node (#4A5163) for nodes not yet checked during a step.

Assumptions — please confirm

  • Font: Atkinson Hyperlegible Next + Mono (free, Google Fonts). Easy to swap.
  • Progress map completion uses neutral ink, not the mastery colours, so “done” is never confused with “secure”.
  • On a first miss, the correct option is not revealed; it is shown at the retry cap (3 tries).
  • Remember and Secure share teal #0F766E as specified; they never sit side by side without their word/shape, so this shouldn't confuse.
  • Dark theme hues are my proposal; light is the priority for the screens.
